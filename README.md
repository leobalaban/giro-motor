# Giro Motor

Revista digital de carros feita como projeto da disciplina **Desenvolvimento Front-End para Web** (Universidade Positivo, Prof. Fabricio Olivo).

**Site on-line:** https://leobalaban.github.io/giro-motor/

## Autores

- Leonardo Balaban
- Matheus de Alice

## Tecnologias

- HTML5 semântico
- CSS3 (Flexbox, Grid e @media)
- JavaScript puro (eventos, DOM e localStorage)
- Bootstrap 5.3 (arquivos locais, funciona offline)

## Páginas

| Página | Conteúdo | Bootstrap |
|---|---|---|
| index.html | Boas-vindas com nome salvo, destaques e dica do mês | Sim |
| QuemSomos.html | A revista e a dupla | Não |
| Modelos.html | Catálogo de 10 carros com filtro por categoria e botão para adicionar à garagem | Sim |
| FichaTecnica.html | Tabela da Ford Ranger Raptor | Não |
| Comparativo.html | Ranger Raptor x Hilux GR-S | Sim |
| Galeria.html | 8 fotos em CSS Grid com ampliação | Não |
| Midia.html | Vídeo e áudio com controles nativos | Sim |
| Eventos.html | Eventos com confirmação de presença salva no localStorage | Sim |
| Contato.html | Formulário com validações nativas | Sim |
| Garagem.html | Cadastro de carros salvo no localStorage, com confirmação antes de limpar | Sim |

## Como abrir

Baixe o projeto e abra o arquivo `index.html` no navegador. Não precisa de internet nem de servidor.

## Estrutura

```
index.html e demais páginas
css/    bootstrap.min.css e Estilos.css
js/     bootstrap.min.js e um script para cada página
img/    fotos
video/  vídeo
audio/  áudio
doc/    documentação em formato ABNT
```
